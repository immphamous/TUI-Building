ℹ️ Made for linux

A simple, yet shockingly unoptimized game I made in about two days. Partially inspired by minecraft, but pretty much nothing like it.
I used dictionaries instead of classes because I used Lua recently and had partially enjoyed how OOP was done in it.

You usually use items with `W`, and sometimes have to use the arrow keys to signify where the action should take place.
The `[]` are rocks which you can pick up with a stick, and the trees are chopped down with the axe.
You have to press `W` and then the arrow key of where the crate is in order to open it. You shouldn't be holding anything at that time.

Very slow as the rendering code is unoptomized.
